# Backend Seguro para Ollama

Estrutura do projeto para intermediar e proteger o acesso à API do Ollama.

O código da aplicação, configurações Docker e documentação completa estão localizados dentro do diretório:

📁 **[`servidor/`](file:///Users/rafael.selvagio/Projetos/MyApps/ProjetosServidorDidatico/backend_ollama/servidor)**

---

### Início Rápido:

```bash
# 1. Acessar o diretório da aplicação
cd servidor/backend

# 2. Executar testes automatizados
npm test

# 3. Executar o backend em modo de desenvolvimento local
npm run dev

# 4. Build de produção
npm run build
```
